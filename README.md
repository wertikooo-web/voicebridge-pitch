# 🎙️ VoiceBridge — Pitch Simulator

Интерактивный симулятор питча для практики ответов на вопросы инвесторов.

Тренируйся отвечать на острые вопросы от 4 типов инвесторов — а Claude AI играет роль инвестора и реагирует на каждый твой ответ.

🔗 **[Открыть симулятор →](https://wertikooo-web.github.io/voicebridge-pitch)**

---

## Что это

VoiceBridge — платформа голосового присутствия для пожилых людей и их семей.
Одно касание устройства → уведомление сыну или дочери → живой голосовой канал.
Без смартфона. Без экрана. Без обучения.

Этот симулятор помогает фаундерам готовиться к инвестиционным встречам.

## Как запустить

1. Открой страницу по ссылке выше
2. Вставь свой API ключ Anthropic при первом открытии
3. Выбери инвестора и начинай питч

Получить API ключ: [console.anthropic.com](https://console.anthropic.com)  
При регистрации даётся $5 бесплатного кредита.

> Ключ хранится только в твоём браузере (localStorage). Никуда не отправляется.
